# Сохранённые эксперименты

Минимальный код для воспроизведения финального исследования. Скрипты перенесены без изменений из работ Амира и Азамата; отдельные черновики удалены после синтеза. Официальные данные, среда и scorer находятся только в `project-context/case-files/`.

| Скрипт | Автор | Назначение |
|---|---|---|
| [research_data_audit.py](research_data_audit.py) | Амир | Аудит CSV, пропусков, размеров групп и пересечений ID |
| [research_mechanics_checks.py](research_mechanics_checks.py) | Амир | 19 проверок публичной механики на придуманных данных |
| [priors_audit.py](priors_audit.py) | Азамат | Историческое покрытие действий при альтернативной очистке |
| [portfolio_toy.py](portfolio_toy.py) | Азамат | Маленький оптимизатор и точный перебор |
| [exploration_toy.py](exploration_toy.py) | Азамат | Сравнение трёх политик разведки в четырёх мирах |

Запускать единый runner **из корня репозитория** в окружении с NumPy/pandas:

```bash
python final-research/evidence/verify.py
```

Runner устанавливает пути к официальному пакету и перенаправляет промежуточные отчёты во временную папку. Скрипты сохранены как исследовательские модули: их старые самостоятельные точки входа не настраивают пути нового расположения. Не запускайте их для записи результатов в каталог исходного кейса.

[expected.json](../expected.json) содержит пять эталонных отчётов, авторство, SHA-256 скриптов и исходные пути в Git на коммите `5c39de98e0b75773918c2060af34fff88f07e9bd`. Эти исторические пути — сведения о происхождении, не зависимости запуска. Итог повтора — [results.json](../results.json); методика и ограничения — [VALIDATION.md](../../VALIDATION.md).
