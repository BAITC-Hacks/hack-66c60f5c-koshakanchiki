# Как готовить и проверять сдачу

Этот документ связывает [техническое ТЗ](case-files/PARTICIPANT_GUIDE.md) с [правилами мероприятия](RULES.md). На момент создания контекста финальный агент в этом репозитории ещё не готов.

## Требуемые артефакты кейса

| Артефакт | Назначение |
|---|---|
| `agent.py` | Класс `Agent` с `act(env)`, который использует `env.run_pilot` и возвращает 1–10 корректных кампаний |
| `submission.csv` | Выход команды `python make_submission.py`; содержит финальные кампании |
| `requirements.txt` | Зависимости, если они нужны сверх доступной среды |
| `README.md` | Назначение, архитектура, технологии, команды запуска и проверки; обязателен по положению |

## Проверка перед отправкой

1. В выданном для сдачи репозитории запустить `python local_eval.py`: агент не падает, проводит хотя бы один пилот, итоговые кампании корректны, лимиты соблюдены.
2. Запустить `python local_eval.py --runs 10` для оценки чувствительности к шуму и выборке в одной mock-среде. Для устойчивости стратегии дополнительно сравнить сценарии с другими скрытыми эффектами; не обещать по mock итоговый балл.
3. Запустить `python make_submission.py`, проверить существование и схему `submission.csv`. Эта команда экспортирует только финальные кампании и проверяет их иначе, чем `local_eval.py`; оба шага необходимы.
4. Проверить 10-минутный лимит, отсутствие ключей в коде, актуальный README и воспроизводимость запуска без личных аккаунтов. Если используется LLM API, ключ брать из окружения, а ошибку API обрабатывать.
5. Зафиксировать код и документацию в **выданном платформой** репозитории до официального окончания разработки. Затем выполнить «Сдать решение» на странице трека и убедиться, что отправка зарегистрирована.

Согласованный [план испытаний](../final-research/VALIDATION.md) уже подготовлен: он разделяет выполненные исследовательские проверки и будущее сравнение агента на независимых мирах эффектов. Реализация должна следовать [техническому плану](../final-research/ALGORITHM.md). Скрипты в `final-research/evidence/` воспроизводят исследования; готовый соревновательный агент ещё не создан.
